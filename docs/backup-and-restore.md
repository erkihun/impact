# Backup and restore

Back up MySQL and private object storage with encryption, access logging and retention aligned to policy. Application keys and infrastructure configuration require a separate protected recovery channel.

Restore drills must prove:

- point-in-time database recovery;
- object/database consistency;
- decryptability with controlled keys;
- audit-chain availability;
- measured RPO/RTO;
- post-restore readiness and representative user journeys.

Do not claim recoverability from successful backup jobs alone.
