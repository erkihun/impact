# Design discrepancies and resolutions

| ID | Source conflict or issue | Working resolution | Status |
|---|---|---|---|
| DD-001 | SRS content workflow includes `Unpublished`; LLD enum omits it | Preserve `unpublished` because unpublish is a mandatory public-content operation | Accepted implementation assumption |
| DD-002 | SRS lead statuses and LLD submission statuses use different vocabularies | Use the LLD operational sequence and retain terminal/qualification values as a superset | Product-owner confirmation required |
| DD-003 | Several LLD generated state/action tables map unrelated actions to modules | Treat prose requirements and domain invariants as authoritative over invalid generated mappings | Confirmation required |
| DD-004 | LLD persistence mappings reference unrelated table names for search/RBAC | Use normalized tables described elsewhere in the LLD schema catalogue | Confirmation required |
| DD-005 | LLD specifies MySQL `BINARY(16)` UUIDv7 while Laravel relations and route binding natively use canonical UUID strings | Current migrations store canonical UUIDv7 strings; a `BinaryUuid` cast exists but is not activated | Open architecture decision before production data |
| DD-006 | Baseline requires PHP 8.4; workstation provides PHP 8.2.12 | Enforce 8.4 in Composer, keep locally tested source 8.2-parseable, certify in PHP 8.4 CI | Open environment blocker |
| DD-007 | MFA is mandatory but no provider/recovery-code UX is fully specified | Implement RFC 6238 TOTP with encrypted secret and hashed one-use recovery codes using `pragmarx/google2fa` | Implemented assumption; security review pending |
| DD-008 | SRS FR-SEO-001/005/010, §9.2 and SDD §6.16 require localized metadata, hreflang, locale-segmented sitemaps and language-aware URLs (English/Amharic) | **Approved direction: English-only.** No locale prefix, no hreflang/x-default, one English sitemap index, no Amharic metadata or translation-readiness checks. Retired `/en/...` URLs 301 to unprefixed URLs; retired `/am/...` URLs 301 to the equivalent English page or return 410. See `seo-english-only-migration.md`. | Approved deviation (2026-10-06) |
| DD-009 | LLD §20.1.29 defines `seo_metadata` as polymorphic (`seoable_type/id`) and locale-keyed | Overrides are keyed by `subject_type` + `subject_key` (page key or stable resource id) so static pages can be edited and overrides survive content versioning; no locale key | Implemented; the original table was unused and was replaced |
| DD-010 | LLD §19 places redirect management at `/admin/redirects` with `RedirectPolicy`, `CreateRedirectAction`, `ValidateRedirectGraphJob` | Redirects live in the SEO centre (`/admin/seo?section=redirects`, permission `seo.manage`); `SaveRedirectAction` validates on write (loops, chains, targets) and `seo:redirects-validate` replaces the graph-validation job | Implemented assumption |
| DD-011 | LLD names `GenerateSitemapJob` and `PurgeCdnPathJob` | `GenerateSitemapsJob` (unique, locked, atomic) and a `CdnPurger` contract with a logging default, because no CDN provider is specified | CDN provider pending |
| DD-012 | SRS FR-INS (insight author) expects a named author; the insight schema has no author field | Article markup uses the organization as author and publisher; no person is invented | Product-owner confirmation if bylines are wanted |
| DD-013 | Generic CMS content items (`content_items`) have no public route, but were indexed into internal search at `/en/{slug}` | They are not indexed or listed in sitemaps until a public route is configured (`impact.seo.content_item_routes`) | Implemented; product decision needed if generic pages should be public |
| DD-014 | The UI/UX design specification document referenced by the SEO brief is not present in `docs/` | SEO work followed the SRS, SDD, LLD and the existing public UI implementation | Document to be supplied |
| DD-015 | The homepage hero design image was retrieved from a third-party site (`resources/images/reference-assets.md`) without a recorded licence | The 6.4 MB source moved to `resources/images/source` and only optimized derivatives are served; licensing is unchanged | Rights confirmation required before launch |

No discrepancy is silently resolved when it changes user-visible workflow, security or persistence guarantees.
